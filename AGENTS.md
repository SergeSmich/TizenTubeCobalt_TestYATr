# Правила работы (агент build)

## Устройства — обязательно
- `192.168.1.100:5555` (Яндекс ТВ) — рабочее устройство для отладки.
- `192.168.1.200:5555` (SberBox) — **отладку не включать и не использовать**: никаких
  `adb connect`, `logcat`, `screencap`, `monkey`, `input` без прямой просьбы
  пользователя. Только явно запрошенный деплой (`adb install -r`).

## Экономия токенов/лимита — обязательно
- Никогда не выполняй `adb logcat -d` без `-s <тег>`; предпочитай `adb logcat -d -s VotBridge` (короткие строки моста).
- Не выводи сырые консольные логи `cobalt` целиком: строки CSP содержат список из ~200 доменов (3–6 КБ каждая). Фильтруй по маркерам `[VOT]` / `[VOT-boot]` и обрезай вывод.
- Читай файлы частями (read с offset/limit), а не целиком, если нужен только фрагмент.
- Батчь правки и shell-команды; избегай лишних полных пересборок APK (пересобирай dex точечно, кэшируй артефакты).
- Механическую работу (сборка/установка/чтение логов/проверка) делегируй субагенту `tester`, поиск по коду — `explore`.

## Роутинг субагентов (модели заданы в opencode.json)
- сборка / установка / чтение логов с ТВ / проверка    → `tester`   (deepseek-v4.1-flash)
- поиск и чтение кода / файлов                        → `explore`  (deepseek-v4.1-flash)
- многошаговые параллельные рутинные задачи           → `general`  (gpt-6-luna)
- сложная архитектура / гонки / C++ / низкий уровень  → `architect` (kimi-k3)
- ревью diff перед коммитом                            → `reviewer` (grok-4.7)

Основная модель (deepseek-v4-pro) — только правки кода и ключевые решения.
