## A. Сервисы перевода названий видео (карточки)
Цель: переводить названия роликов в карточках (сетка/поиск/сайдбар) с нерусского на русский, на устройстве, без ПК.

Сравнить как минимум: Google Cloud Translation v3, DeepL API, Yandex Translate, Azure Translator, LibreTranslate (self-host), MyMemory/Lingva (free), LLM-шлюз (GPT/Claude/Gemini одним прокси). Добавь релевантные, которые найдёшь.

Критерии:
- качество на коротких заголовках: имена, CAPS, эмодзи, смешанный язык, бренды;
- цена за 1k названий и бесплатный уровень; оценка при 200 названиях/день;
- латентность и batch (пачка карточек за один запрос);
- лимиты, ретраи, поведение без сети;
- где живёт ключ (в проекте — только на мосту, на устройстве ключей нет);
- ToS для встраивания в клиент.

Нужно: шорт-лист 2–3 варианта («дешёвый», «качественный», «без ключа/self-host»), рекомендация с fallback-цепочкой, схема запроса через мост (`POST /title_tr` батчем), формат кэша и инвалидации, оценка стоимости.

Важно: названия — не предложения. Промпт/параметры должны запрещать пояснения, не переводить имена каналов и не раздувать строку (1 строка, лимит символов).

## B. Анализ фич и план
По каждой: реализуемость в текущей архитектуре (Cobalt + injected `vot.js` + нативный мост `127.0.0.1:8013`), что нужно (DOM-хук / мост / нативный код / отдельный cookie-профиль), объём, риски, зависимости.
1. Разные настройки для разных аккаунтов.
2. Быстрое переключение региона.
3. Перевод названий видео в карточках + визуальный маркер «переведено».
4. Системная клавиатура (Android IME вместо встроенной YTLR).
5. Перевод поискового запроса по кнопке.
6. Штатные фильтры поиска YouTube.
7. Плейлисты, каналы и свои списки в боковой панели.
8. Long-press → фильтр тайм-кодов/названий фильмов и сериалов → глобальный поиск + поиск в установленных кинотеатрах и агрегаторах.
9. Нейро-поиск: голос с пульта/микрофона → корректный запрос на иностранном языке → выдача.

Формат ответа:
- Таблица: фича | вердикт (реально / частично / невозможно) | как | объём S/M/L | риск | зависимости.
- 3 фазы roadmap с порядком и обоснованием.
- Отдельно: что требует ключей/аккаунтов, что требует нативного кода, что может сломать существующее (перевод звука, панель фильтров, OK на пульте).
- Отдельно маркер переведённого названия: 2–3 варианта для 10-foot UI (иконка после заголовка, цветная точка/полоска, цвет текста) с плюсами/минусами и рекомендацией.

## Контекст и ограничения
- Правило проекта «unknown beats wrong»: маркер показывается только когда перевод реально применён; при ошибке сервиса маркер снимается, оригинал остаётся.
- Ключи и токены — только на мосту (как OAuth в `vot_config_cache.json`).
- Панель фильтров поиска уже кастомизирована — не регрессировать.
- 10-foot UI, фокус пульта: перевод асинхронный, карточка сначала рисуется с оригиналом, сетка не блокируется.
